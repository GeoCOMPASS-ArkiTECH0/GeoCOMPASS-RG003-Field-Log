# GeCCO TCI, CERTWORX, Assessment & Evidence Standard v0.1

## Purpose

Convert descriptor-derived competencies into objectively verifiable certification work without creating unnecessary curriculum or documentation burden.

## Core Chain

**CANON → COMPETENCY → TCI → CERTWORX → ASSESSMENT → EVIDENCE → CERTIFICATION**

## TCI Standard

A **Target Competency Indicator (TCI)** must describe an observable, assessable demonstration of competency.

Each TCI should contain:

- TCI ID
- Competency ID
- Exact descriptor traceability
- Observable performance
- Conditions/context
- Required standard
- Assessment method
- Minimum credible evidence
- Pass condition
- Not-yet/pass remediation condition
- Applicable safety/compliance requirements
- Version

## TCI Quality Test

A TCI fails validation if it is primarily:

- a topic;
- an intention;
- a vague trait;
- a generic learning outcome;
- an unmeasurable claim; or
- unrelated to the canonical descriptor.

A strong TCI answers:

> **What must the candidate demonstrably do, under what conditions, to establish this competency?**

## CERTWORX

**CERTWORX** is the certification-work pathway through which candidates develop, practice, demonstrate, document, and verify the competencies required for a GeCCO credential.

CERTWORX is distinct from generic coursework.

**Curriculum** defines and organizes learning.

**Coursework** may be delivered through broader GeXI educational programs.

**CERTWORX** connects required learning and practice to certification evidence and verified competency.

## Assessment Standard

Assessment should use:

**Observable criterion → Conditions → Evidence → Pass standard**

Evaluator calibration should be used where reasonable differences in evaluator judgment could affect results.

## Minimum Evidence Principle

Collect the **minimum credible evidence** necessary to establish competency.

Evidence must be sufficient to support the certification decision but should not become an administrative burden merely because additional evidence is possible.

## Evidence Classes

Depending on the unit and TCI, evidence may include:

- direct observation;
- practical demonstration;
- simulation;
- structured assessment;
- field log;
- measured output;
- documented artifact;
- evaluator verification; or
- other authorized evidence appropriate to the competency.

## Assessment Integrity

An assessment record should identify:

- Candidate
- Unit
- Competency
- TCI
- Evaluator
- Date
- Conditions
- Result
- Evidence
- Remediation, if applicable
- Assessment version
- Decision authority

## Appeals

Minimum pathway:

**Disputed assessment → authorized review → evidence review → decision → recorded outcome → candidate notification**

Appeals should remain proportionate to the stakes of the credential.

## Certification Readiness Test

Before certification:

- [ ] TCI is descriptor-traceable.
- [ ] TCI is observable.
- [ ] Pass condition is defined.
- [ ] Evaluator is authorized.
- [ ] Required evidence is present.
- [ ] Evidence is sufficient and authentic.
- [ ] Assessment version is locked.
- [ ] Prerequisites are satisfied.
- [ ] Any remediation is resolved.
- [ ] External authority/licensing boundary is respected.

## Fulcrum Rule

**Do not certify paperwork. Certify demonstrated competency.**
